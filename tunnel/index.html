Tunnel manages WireGuard VPN profiles. Generate keys in your browser, paste in a config from your VPN provider or your own server, and send each device its profile by QR code or file. The official WireGuard app does the tunnelling.

Everything Tunnel does

WireGuard VPN profiles for every device.

Keys made on your device

Key pairs are generated in your browser with X25519. Private keys are stored only inside your encrypted Satchel account.

QR code for phones and iPads

Scan a profile straight into the WireGuard app on iOS or Android.

Config files for computers

Download a ready .conf file for WireGuard on Windows, macOS or Linux.

Change your location

Keep a profile per server location, from your own VPS or a provider that offers WireGuard.

Public Wi-Fi privacy

Route traffic through an encrypted tunnel on campus, café or hotel networks.

Setup checker

Tunnel checks every profile for missing keys, bad addresses and DNS leaks before you export it.

Tunnel does not run a VPN server or route any traffic itself. A browser cannot start a system VPN, so connecting is done in the free WireGuard app.
